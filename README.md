# Job Notification Tracker

A Streamlit and SQLite Python course project.

## Run

Use Python 3.10+.

```bash
python3 -m pip install -r requirements.txt
python3 -m streamlit run main.py
```

The application supports sample jobs, an optional remote job API, local bookmarks, and application status tracking.

Run tests with `python3 -m unittest discover -s tests -v`.

Local database files are excluded from version control. This is a single-user local demonstration app.
